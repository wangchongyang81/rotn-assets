## Authority
Nothing in the game ships against this. A conflict between an asset and this
folder is resolved in favour of the folder, or the folder is amended first.

## Change
Amendments are commits to this folder by the venice lane, and they update the
affected file whole rather than appending. A change to 00 re-opens every file.

## Open
Registry build is next, against 05. The variant map is fixed at ten; anchors
generate from V1 and V2 first, then outward.
