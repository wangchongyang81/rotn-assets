## HF layout trap (read before pruning)
The remote holds TWO layouts. `tools/hf/mirror.sh` uploads full paths, so `art/x` exists; `tools/mirror_hf.sh` strips `art/` on upload, so canonical `x` exists too. Rule in `prune.sh`: an `art/` file is orphaned only when its stripped twin exists remotely; a canonical file is kept if it exists on disk even untracked.
